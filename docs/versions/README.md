# Version History and Roadmap

## Purpose

이 폴더는 Cluster의 버전별 설계 기록과 로드맵을 관리한다.

- `docs/` 루트의 문서들은 항상 현재 최신 설계를 기준으로 유지한다.
- `docs/versions/` 문서들은 각 버전의 문제 인식, 설계 방향, 변경 이력, 다음 버전으로 넘긴 범위를 기록한다.

## Version Documents

| Version | Document | Role |
| --- | --- | --- |
| v1 | [v1_mvp.md](./v1_mvp.md) | 기존 MVP 구현과 한계 기록 |
| v2 | [v2_backend_rearchitecture.md](./v2_backend_rearchitecture.md) | 현재 포트폴리오용 백엔드 리빌드 범위 |
| v3 | [v3_service_expansion.md](./v3_service_expansion.md) | 서비스화/확장 로드맵 |

## Version Policy

- v1은 기존 구현을 평가하고 문제를 정리하는 기준이다.
- v2는 현재 집중할 포트폴리오 버전이다.
- v3는 좋은 아이디어지만 v2 범위를 넘는 서비스화/확장 항목을 보관한다.
